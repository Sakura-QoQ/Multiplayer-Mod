# Fallen Flower 联机 Mod——独立服务器版

《Fallen Flower》公开服务器联机 Mod。所有玩家通过内置按钮直接连接 Docker 部署的 Ubuntu 中继。

`PlayerHostedMultiplayer` 仅作为兼容旧版本的包名和文件夹标识保留，不再代表当前生产网络架构。

> **v0.11.0 部署要求：**玩家 Mod 和 Ubuntu 房间服务器必须一起更新；旧服务器不支持一键进入公开房间。

[English documentation](README.md) · [文档索引](docs/README.zh-CN.md) · [验证报告](VERIFICATION.zh-CN.md) · [许可协议中文参考](LICENSE.zh-CN)

## 功能

- 在主菜单增加与原版风格一致的“联机”入口，并提供三个一键公开服务器按钮；玩家无需填写地址、房间 ID 或密码。
- 联机中的暂停菜单入口是只读房间页，仅显示房间身份/公开房间名称、统一时间、在线人数和玩家名单；页面显示时后方世界、物理、动画和线上时钟仍继续运行。
- 默认每个房间最多 8 人，服务器可配置范围为 2–32 人。
- 所有玩家都以普通参与者身份连接。Ubuntu 服务持有房间成员、逻辑权威身份、统一时钟、场景裁决和睡眠共识；玩家无需开放公网端口，也不会获得房主权限。
- 联机游戏内按住 `Tab`，可在屏幕中央查看跟随游戏语言的房间玩家名单。
- 同步人物模型、位置、朝向、移动、落地状态、武器、动作和全部 Animator 层。
- 同步衣服、晒黑肤色、捏脸数据、完整存档资料和持续变化的玩家状态。
- 玩家移动快照为 20 Hz，远端位置、旋转、动画层和衣服骨骼仍在每个渲染帧插值更新。
- 服务器推进唯一的权威时钟，所有玩家持续向它校准；只有服务器收到全部在线玩家相同的睡眠请求，才会推进时间。
- 每名玩家固定使用一个 UUIDv7 线上存档，单机读取/保存页面不会显示线上文件。
- 线上模式退出前必须完成保存并验证，成功后才真正退出。

## 安装

1. 使用游戏专用 Mod 启动器导入 `PlayerHostedMultiplayer-v0.11.0-win-x64.zip`。
2. 通过该 Mod 启动器正常启动游戏。
3. 在主菜单“新建游戏”上方选择“联机”。

发布包已经包含 Windows x64 NativeAOT 网络桥和全部运行依赖。玩家不需要安装 Node.js、TypeScript、.NET、Visual Studio，也不需要运行额外启动脚本。
桥接程序使用当前用户的普通权限运行，不会申请管理员提权。独立服务器模式只需要玩家电脑具备出站 TCP 访问能力，不需要 Windows 入站防火墙规则或路由器端口映射。

## 快速使用

1. 输入玩家名称。
2. 点击“公开服务器 1”“公开服务器 2”或“公开服务器 3”。
3. 服务器会原子地加入已有公开房间，或在房间为空时自动创建；不使用密码。
4. Mod 会继续该玩家自己的 UUIDv7 线上存档；只有确实没有线上档时才从零创建。

服务器端点以 AES-GCM 加密常量保存在原生桥接程序内，不写入 `config.json`、UI 或语言文件。这能避免明文暴露和随手修改，但客户端必须包含解密材料，因此属于静态隐藏而不是绝对保密。所有玩家必须使用相同游戏和 Mod 版本。玩家退出只移除自己；公开房间由服务器保留，直到管理员关闭或服务重启。

## 同步方式

- 玩家状态以 20 Hz 发送以提高移动响应；变化较慢的服务器权威时间仍以 5 Hz 发送。
- 线上时间由 Mod 的非缩放权威时钟推进，因此任何电脑打开暂停/设置界面都不会停止或分叉房间时间。
- 画面仍逐帧更新：远端位置、旋转、动画层和衣服骨骼会向最新网络快照平滑插值。
- 完整 `GetSave()` 资料过大时会自动分片，接收端按修订号重组并为每名远端玩家保存。
- 生命、耐力、金钱、时间和场景等高频字段使用更小的实时资料包。
- 远端角色是纯显示克隆，激活前会移除输入、相机、碰撞和游戏逻辑脚本。

游戏存档包含照片记录和索引，但不包含外部 PNG 图片字节；这些外部图片文件目前不会传输。

## 线上存档隔离

- 正式文件：`MPOnline_<玩家 UUIDv7>.save`。
- 恢复工作副本：`MPActive_<玩家 UUIDv7>.save`。
- 两种文件都会从原版单机读取/保存页面中过滤。
- 内层完全兼容游戏原版 `Encrypted` 格式：PBKDF2-SHA256、AES-256-CBC 和 HMAC-SHA256。
- Mod 外层使用 PBKDF2-SHA256 和 AES-256-GCM 认证加密。
- 保存采用原子写入；工作副本会保留用于恢复，原版 `AutoSave*.save` 不会被覆盖。

## 构建与验证

开发机需要 .NET 8 SDK 和 Visual Studio x64 C++ 工具，用于 NativeAOT 链接。详细说明见
[开发指南](docs/DEVELOPMENT.zh-CN.md) 和 [架构说明](docs/ARCHITECTURE.zh-CN.md)。

```powershell
./build.ps1 -Install
./artifacts/bridge/win-x64/MultiplayerBridgeHost.exe --self-test-save-crypto
```

已验证范围和证据路径见 [VERIFICATION.zh-CN.md](VERIFICATION.zh-CN.md)。

## 支持环境

- Windows x64
- 安装游戏专用 Mod 启动器的 Fallen Flower
- 安装 Docker Engine 与 Compose 插件的 Ubuntu/Linux 服务器
- 所有参与者使用相同游戏版本和 Mod 版本
