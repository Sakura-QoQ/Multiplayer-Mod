Fallen Flower 联机 Mod——公开服务器版 v0.11.0 — Windows x64

安装
1. 使用游戏专用 Mod 启动器导入本包。
2. 通过 Mod 启动器启动游戏，不需要额外启动脚本。
3. 在主菜单“新建游戏”上方选择“联机”。

发布包包含自包含的 MultiplayerBridgeHost.exe 和全部运行依赖。玩家不需要安装 .NET、
Node.js、TypeScript、Visual Studio 或其他开发软件。
桥接程序使用普通用户权限，不会申请管理员提权。公开服务器模式只需要出站 TCP 访问，玩家
不需要开放入站端口。

公开服务器
- 输入玩家名称，然后点击“公开服务器 1、2 或 3”；无需填写地址、房间 ID 或密码。
- 房间服务器会加入现有公开房间，房间为空时自动创建。
- Ubuntu 服务器负责成员、逻辑权威身份、统一时间、场景裁决和睡眠共识；所有玩家都是普通参与者。
- 玩家退出只移除自己；公开房间保留到管理员关闭或服务重启。
- 每名玩家继续自己的 UUIDv7 线上存档；只有没有线上档时才从零创建。
- 进入联机游戏后按住 Tab，会在屏幕中央显示房间内玩家名单。
- 服务器端点以 AES-GCM 加密形式保存在原生桥接程序内，不写入 config.json 或 UI。

同步
Mod 会同步人物模型、位置、朝向、动作、全部 Animator 层、衣服、晒黑肤色、捏脸、完整
存档资料、实时状态、服务器裁决场景和服务器权威时间。玩家移动快照为 20 Hz，服务器权威时间为 5 Hz，
画面会在每个渲染帧平滑更新。
只有所有在线玩家同意相同睡眠方式后，睡觉才会推进时间。
服务器接管线上时间流逝。PauseWindow 保持显示时，同步的本地时钟以及菜单后方世界仍会
继续运行。
暂停菜单中的“联机”只显示只读房间信息：身份/公开房间名称、统一时间、在线人数和玩家名单；
公开服务器入口只在主菜单提供。

存档
线上正式档命名为 MPOnline_<玩家 UUIDv7>.save，MPActive_<玩家 UUIDv7>.save 是保留的恢复
副本。两者都不会出现在原版单机存档界面。线上退出前会保存并验证双层加密文件，且不会覆盖
单机 AutoSave。

语言
游戏内 UI 会跟随游戏当前语言。语言包包含英语、日语、简体中文、繁体中文、韩语和西班牙语。
