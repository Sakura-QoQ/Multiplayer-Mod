Fallen Flower 联机 Mod——公开服务器版 v0.13.0——Windows x64

安装
1. 使用游戏 Mod 启动器导入本包。
2. 通过该启动器启动游戏，不需要额外脚本。
3. 点击“新建游戏”上方的“联机”。

本包包含自包含 MultiplayerBridgeHost.exe。玩家不需要安装 .NET、Node.js、TypeScript、
Visual Studio 或其他开发软件。桥接程序以当前普通用户运行，不申请管理员权限，也不使用注册表 IPC。

进入联机
- “公开服务器”显示服务器实际管理的房间与实时人数/容量。服务器启动时建立一间，全部满员后
  才增加下一间，并回收多余空房间。选择列表房间无需输入地址或密码；玩家只需要出站 TCP。
- 公开容量只由 FF_ROOM_MAX_PLAYERS 决定；localMaxPlayers 只用于本地建立房间。
- 本地“建立/加入”仍保留地址/端口控件；玩家电脑跨公网当直连房主时可能需要开放防火墙和路由器端口。
- Ubuntu 服务固定为逻辑权威 Peer 0；包括第一名在内，所有公开玩家都是正数 ID 普通成员。
- 联机内按住 Tab 显示居中名单；暂停菜单“联机”页面只读，后方世界和统一时钟继续运行。

同步
玩家位置/动作快照为 20 Hz；远端位置、Animator 层和衣服骨骼逐帧更新。衣服、晒黑肤色、
捏脸、完整资料快照和实时状态用于远端外观/信息；其他玩家进度不会合并到你的存档。服务器发送
5 Hz 权威时钟，只有全部在线玩家请求相同睡眠方式才会批准推进。

存档
正常情况下只持久存在 MPOnline_<UUIDv7>.save。MPActive_<UUIDv7>.save 只为游戏读取原生加密
格式临时生成，加载后删除。加载完成前强制只读。线上自动保存会取消原版
SaveGame("AutoSave") 磁盘写入，把内存 GetSave() 直接提交到 MPOnline；线上流程不读取或写入
单机 AutoSave.save。退出前必须保存并验证 MPOnline。

安全
存档文件在磁盘上使用双层加密。网络是明文 TCP 分帧 JSON，不是 TLS；内置端点只是混淆，
不是秘密。不要把存档加密误认为网络数据包也已加密。
