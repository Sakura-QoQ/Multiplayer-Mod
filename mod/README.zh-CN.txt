PlayerHostedMultiplayer v0.9.0 — Windows x64

安装
1. 使用游戏专用 Mod 启动器导入本包。
2. 通过 Mod 启动器启动游戏，不需要额外启动脚本。
3. 在主菜单“新建游戏”上方选择“联机”。

发布包包含自包含的 MultiplayerBridgeHost.exe 和全部运行依赖。玩家不需要安装 .NET、
Node.js、TypeScript、Visual Studio 或其他开发软件。

建立房间
- “建立并进入”会继续玩家现有的 UUIDv7 线上存档。
- 只有磁盘上没有线上档时才会从零创建。
- 局域网玩家填写房主电脑的局域网 IPv4 和设定的 TCP 端口。
- 公网建房通常需要允许 Windows 防火墙端口并设置路由器端口映射，或使用可信虚拟局域网工具。

同步
Mod 会同步人物模型、位置、朝向、动作、全部 Animator 层、衣服、晒黑肤色、捏脸、完整
存档资料、实时状态、场景和房主权威时间。网络快照为 5 Hz，画面会在每个渲染帧平滑更新。
只有所有在线玩家同意相同睡眠方式后，睡觉才会推进时间。

存档
线上正式档命名为 MPOnline_<玩家 UUIDv7>.save，MPActive_<玩家 UUIDv7>.save 是保留的恢复
副本。两者都不会出现在原版单机存档界面。线上退出前会保存并验证双层加密文件，且不会覆盖
单机 AutoSave。

语言
游戏内 UI 会跟随游戏当前语言。语言包包含英语、日语、简体中文、繁体中文、韩语和西班牙语。
